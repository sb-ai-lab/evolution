# Руководство пользователя Evolution Lab

[English](../README.md) · Русский

> Русский перевод может отставать от английской версии.

Evolution Lab помогает честно измерить LLM-агента и улучшить его с помощью
Evolution Core: фиксирует входы, запускает агента как сервис, измеряет его и
показывает изменения, не выдавая ошибку инфраструктуры за качество агента.

## Работа с кодинг-ассистентом

В Lab есть готовые навыки, с которыми ассистент поможет подключить агента, подготовить оценку, запустить кампанию и разобрать результаты. [Собрать и установить плагин для своего репозитория](../../../plugins/README.md#build-and-install).

## Перед началом

Руководство предназначено для **разработчиков, впервые знакомящихся с Lab**.
Предполагается знание Python и наличие агента, с которым вы хотите работать;
знание Lab или Evolution Core не требуется. Страницы объясняют, зачем что-то
нужно, прежде чем показать, как это сделать, и определяют термины при первом
упоминании. Работа со своим агентом начинается с **шаблона проекта**:
`lab new-project DIR` создаёт небольшой проект с агентом-заглушкой, адаптером,
корпусом и оценщиком, а `lab evaluate DIR` измеряет его (новое в 0.0.3.dev72).
Демо и запускаемые примеры используют тот же шаблон. Небольшой **ассистент для
поиска заказов** с инструментом `lookup_order` показывает, что добавляет реальный
агент: настройки, инструменты и обработку ошибок.

Текущая пара версий: `evolution-lab 0.0.3.dev81` и строго
`evo-skills 2.0.0b22` (выпуск с тегом `lab-v0.0.3.dev81`; контрольные суммы wheel
и происхождение исходников — в `docs/RELEASES.md`). Linux или macOS, Python ≥ 3.11.4,
сборка из исходников (на PyPI пакетов пока нет). Другие пары: [RELEASES](../../../lab/docs/RELEASES.md).

На macOS процесс может пережить остановку, если выйдет из группы, исчезнет из дерева между опросами и скроет метку окружения. Нативная установка описана в [заметках для macOS](install.md#заметки-для-macos).

## Выберите свой путь

Начните с разделов [Как работает Lab](concepts.md) и [Установка](install.md),
затем запустите [демо](demo.md), чтобы увидеть, как Lab измеряет и улучшает
синтетического агента. Чтобы до написания своего агента увидеть полный
минимальный пример подключения, прочитайте [Обзор примеров](examples.md).
Затем выберите путь по вашей цели.

### «Я хочу измерить своего агента»

Вам нужна надёжная оценка текущего состояния агента — baseline.

1. [Подключение агента](connect-agent.md) — `lab new-project` и правки файлов
2. [Первая оценка](first-evaluation.md) — `lab evaluate`, вывод и файлы запуска
3. [Входы оценки](evaluation-inputs.md) — реальные кейсы и оценщик
4. [Результаты](results.md)
5. [Подводные камни](pitfalls.md)

### «Я хочу улучшить своего агента»

Вы хотите, чтобы Evolution Core предлагало изменения и сохраняло только те,
которые дают измеримое улучшение. Быстрее всего увидеть весь цикл на бесплатном
демо-проекте — без модели, сети и git, до расходов на своего агента: в разделе
[Проекты и сценарии](projects.md) показаны `connect` и один цикл `evolve`.
Затем пройдите путь измерения со своим агентом: для кампании нужны те же
подключённый агент и входы оценки, а baseline пригодится для сравнения.

1. [Проекты и сценарии](projects.md) — бесплатный демо-проект
2. Все шаги пути «Я хочу измерить своего агента»
3. [Запуск кампании](campaign.md)
4. [Бюджет и контроль расходов](budget.md)
5. [Результаты](results.md) — diff и экспорт итоговой версии

### «Я интегрирую Lab в свой инструмент или сервис»

Вы создаёте программу, которая готовит эксперименты и управляет Lab, как это
делает приложение auto-evolve.

1. [CLI и локальный сервис](cli.md) — сервис через Unix-сокет и его команды
2. [Входы оценки](evaluation-inputs.md) и [Запуск кампании](campaign.md)
   — что должен содержать пакет
3. [Результаты](results.md)
4. Каталог требований: `lab guides requirements --json` перечисляет все пункты,
   которые должен покрыть пакет, и выдаёт digest, который можно закрепить

## Где найти точный справочник

Это руководство обучает работе и не перечисляет все поля и коды ошибок. За
точным контрактом обращайтесь к следующим источникам:

- **Гайды внутри wheel** — [`src/evolution_lab/guides/`](../../../lab/src/evolution_lab/guides/).
  Они написаны как компактные спецификации (частично для AI-ассистентов), а копия
  в установленном wheel всегда соответствует установленной версии. Найти их
  помогают `lab guides list` и `lab guides path`.
- **Справочник API** — [`docs/api/`](../../../lab/docs/api/): подготовка, Owner, сервис,
  бюджетный шлюз и прежний runner.
- **Примеры** — [`examples/`](../../../lab/examples/README.md); начните с
  `examples/owner/evaluation.py`, а [обзор примеров](examples.md) объяснит его
  файлы. Большинство остальных примеров привязаны к старым парам версий и
  сохранены для чтения.
