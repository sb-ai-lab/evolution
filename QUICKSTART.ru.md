# Быстрый старт

[English](QUICKSTART.md) · [Русский](QUICKSTART.ru.md)

Это руководство проведёт вас от клона репозитория до замера вашего собственного агента, а затем до кампании, которая пытается его улучшить, — всё через Evolution Lab. Первым двум шагам после установки не нужны API-ключ, вызовы модели и сеть. Чтобы работать с Core без Lab, используйте [быстрый старт Core](docs/core-quickstart.ru.md).

Нужны Linux или macOS, Python 3.12 или 3.11 (3.11.4 или новее), [uv](https://docs.astral.sh/uv/), [just](https://just.systems/), git и доступ на чтение к этому репозиторию. [Руководство по установке](docs/guide/ru/install.md) объясняет каждое требование.

На macOS процесс может пережить остановку, если выйдет из группы, исчезнет из дерева между опросами и скроет метку окружения.

## 1. Установка

```sh
git clone https://github.com/sb-ai-lab/evolution.git
cd evolution/lab
just setup
just lab guides list
just lab scenarios list
```

`just setup` собирает wheel Core из этого репозитория по последнему коммиту, изменившему что-либо вне `lab/`, собирает wheel Lab из этого checkout и ставит оба в `.lab/venv`. Запускайте его снова после каждого `git pull`. В этом checkout `just lab COMMAND` запускает `lab` из этого окружения. Если установка остановилась, см. [Установка → Устранение неполадок](docs/guide/ru/install.md#устранение-неполадок).

Обе команды со списками работают офлайн и показывают, где найти навыки, которые поставляются с Lab.

- `just lab guides list` перечисляет справочные навыки по подключению агента, подготовке оценки или кампании и чтению результатов. Пути к файлам указаны относительно каталога, который выводит `just lab guides path`.
- `just lab scenarios list` показывает число шагов и путь к файлу навыка для каждого сценария проекта. В списке есть `connect`, `create-skill`, `evolve` и `restructure`.

Чтобы использовать навыки в своём репозитории, [соберите и установите плагин](plugins/README.md#build-and-install) для Qwen Code, GigaCode CLI, Codex или Hermes Agent. Для уже зарегистрированного проекта Lab может [создать рабочее пространство ассистента](docs/guide/ru/projects.md#шаг-8-работа-с-ассистентом) с навыками и подключением по MCP.

По умолчанию Lab и Core переживают сбои процессов без fsync на каждую запись; сбой ОС или потеря питания могут потерять последние изменения. Задайте `EVOLUTION_DURABILITY=strict` до запуска Lab, чтобы вернуть прежнюю сохранность. Базы по умолчанию используют WAL+NORMAL, файлы `-wal` и `-shm` рядом с ними ожидаемы. Lab передаёт действующий режим своим рабочим процессам. Подробнее: [сохранность](docs/guide/ru/cli.md#сохранность-при-сбое-хоста).

## 2. Посмотрите офлайн-демо

```sh
just demo
just demo-campaign
```

`just demo` измеряет агента-заглушку полной фиксированной оценкой: фиксирует входные данные в Bundle, проверяет, что агент говорит по протоколу, оценивает три вопроса и печатает каждый ответ с баллом. `just demo-campaign` даёт Core улучшить демо-агента: балл растёт с 0 до 1, а `changes.diff` показывает строку, которую переписал редактор. [Демо](docs/guide/ru/demo.md) объясняет оба запуска и какие файлы открыть.

## 3. Измерьте своего агента

```sh
just new-project ~/my-agent-lab
just evaluate ~/my-agent-lab
```

`just new-project DIR` пишет каркас проекта: агента-заглушку (`agent/my_agent.py`), адаптер, который подключает его к Lab (`agent/adapter.py`), три вопроса в `corpus.jsonl` и оценщик. Запустите `just evaluate DIR` один раз на нетронутом каркасе, чтобы увидеть успешный запуск, затем замените агента, вопросы и оценщик. [Подключение агента](docs/guide/ru/connect-agent.md) говорит, что править в каждом файле, а [Первая оценка](docs/guide/ru/first-evaluation.md) объясняет вывод, файлы запуска и коды выхода.

## 4. Запустите кампанию

```sh
just campaign ~/my-agent-lab
```

Кампания повторяет раунды «правка — замер — сравнение» по правилам Core и сохраняет лучшую версию. Шаблон работает офлайн с примерами ролей. Замените их для своего агента; модельные роли требуют расходов. Кампания использует `manifest.json` и `campaign-launch.json` того же проекта. [Кампания](docs/guide/ru/campaign.md) ведёт от офлайн-примера к вашему манифесту, области правок, редактору, лимиту расходов и итогу. [Бюджет и контроль расходов](docs/guide/ru/budget.md) объясняет, как Lab ограничивает траты на LLM.
