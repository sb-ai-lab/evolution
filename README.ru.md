# Исследуйте. Редактируйте. Сравнивайте.

[English](README.md) · [Русский](README.ru.md)

Превращайте ошибки своего агента в предлагаемые изменения его навыков и промптов. Evolution проверяет каждое изменение на ваших кейсах, прежде чем выбрать версию.

[Посмотреть статичный пример](docs/assets/readme/evolution-film-poster.png).

## Улучшение инструкции начинается с конкретной ошибки.

Агент даёт общие советы по удержанию пользователей, не проверяя данные продукта. Исследование выявляет недостающий запрос. В предложенной версии навыка теперь сказано запросить данные и сравнить когорты по удержанию. Evolution проверяет кандидата; ваши проверки определяют, будет ли он выбран.

Вы предоставляете агента, редактируемые файлы, кейсы и оценщик. Evolution сохраняет выбранные файлы и историю запусков. Кампания может сохранить текущую версию.

Python 3.11.3+ · Бета `2.0.0b18` · [Apache 2.0](LICENSE)


## Быстрый старт

Запустите полный пример без API-ключа. В нём используются детерминированный агент и роли по заданному сценарию, поэтому он проверяет работу связки компонентов, а не качество реального агента. Используйте Python 3.11.3+ и Bash или Zsh.

### 1. Установите эту бета-версию

```bash
git clone https://github.com/sb-ai-lab/evolution.git
cd evolution
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[tree]"
evo --version
```

Ожидаемый вывод — `evo 2.0.0b18`. Установите пакет из описанной в документации рабочей копии бета-версии или предоставленного wheel-файла; обычная установка из PyPI может установить другой выпуск. Если ваша рабочая копия сообщает другую версию, следуйте документации для неё. [Установка из wheel-файла](QUICKSTART.ru.md#1-установите-бета-версию) описана в полном руководстве.

### 2. Запустите сервис примера

В терминале 1, из того же каталога `evolution`:

```bash
evo-target init ./demo
evo-target serve ./demo/manifest.json
```

Дождитесь строки JSON с `"status": "listening"` и оставьте сервис работающим. Если порт 8765 занят, остановите этот сервис, измените `target.base_url` в `demo/manifest.json`, указав свободный локальный порт, и перезапустите сервис до первой кампании. Если `demo` уже существует, используйте новое имя каталога во всех этих командах.

### 3. Запустите кампанию

Откройте терминал 2 в том же каталоге `evolution` и активируйте то же окружение:

```bash
source .venv/bin/activate
evo tree conformance --manifest ./demo/manifest.json
evo tree evolve --manifest ./demo/manifest.json --run-dir ./demo/run-1 \
  > ./demo/result.json
```

Проверка соответствия должна сообщить `"ok": true` и `"leaked": []`. Кампания сохраняет JSON с результатом в `demo/result.json`, а свои записи — в `demo/run-1`.

### 4. Посмотрите выбранные файлы

```bash
python - <<'PYRESULT'
import json
from pathlib import Path

result = json.loads(Path("demo/result.json").read_text())
print("State:", result["terminal"])
print("Outcome:", result["finished"])
print("Champion:", result["status"]["final_champion"])
print("Files:", result["status"]["campaign_outcome"]["champion_path"])
PYRESULT
cat ./demo/seed/skills/SKILL.md
cat ./demo/run-1/artifacts/champions/v1/skills/SKILL.md
```

Ожидается завершённая кампания с исходом `completed`, причиной `rounds_exhausted` и **Champion `v1`**. Выбранный навык начинается с `IMPROVED`; исходный — нет. Оценщик примера вознаграждает этот маркер, поэтому результат демонстрирует передачу файлов и выбор версии. Он не доказывает улучшение реального агента.

Когда закончите, остановите сервис сочетанием Ctrl+C в терминале 1. Подсказка `continue:` после успешного завершения — необязательная инструкция для следующей кампании. Чтобы повторить пример, запустите сервис и используйте новый каталог запуска.

В [полном руководстве по быстрому старту](QUICKSTART.ru.md) описаны создаваемые файлы и устранение неполадок. При незнакомой ошибке начните с [диагностики и восстановления](docs/running-campaigns.md#a-run-failed-start-here). Справочные руководства по ссылкам доступны на английском языке.

## Что происходит между правкой и выбором версии?

Grouper собирает наблюдаемые ошибки; Reflector исследует группу; редактор меняет копию разрешённых файлов. Предварительные проверки сравнивают Candidate на затронутых обучающих кейсах. Затем финалист проходит новое измерение на обучающих кейсах и сравнение с текущим Champion. Кампания может завершиться без смены выбранной версии. [Подробнее о правилах сравнения](docs/architecture.md#how-promotion-is-decided).

Evolution меняет файлы инструкций без обучения весов модели. Результаты на обучающих кейсах направляют правки и выбор; отложенные кейсы отдельно измеряют качество зафиксированной выбранной версии.

## Подключите своего агента

Вашему агенту нужна обёртка **Target Service**, которая загружает каждый переданный снимок файлов и возвращает результат работы агента. URL провайдера модели — отдельное подключение. В [руководстве по интеграции](docs/connecting-an-agent.md) и [полном примере бэкенда без внешних вызовов](docs/target-server.md#a-complete-offline-backend) показано, что нужно реализовать.
