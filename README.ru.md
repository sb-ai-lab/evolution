# Исследуйте. Редактируйте. Сравнивайте.

[English](README.md) · [Русский](README.ru.md)

Превращайте ошибки своего агента в предлагаемые изменения его навыков и промптов. Evolution проверяет каждое изменение на ваших кейсах, прежде чем выбрать версию, и сохраняет текущую версию, если ни одно изменение не лучше.

**[Попробовать без API-ключа →](QUICKSTART.ru.md)** · [Подключить своего агента](docs/guide/ru/connect-agent.md) · [Как это работает](docs/guide/ru/concepts.md)

**Работайте с Evolution через привычного кодинг-ассистента.** Готовые навыки подскажут ему, как подключить вашего агента, подготовить оценку, запустить кампанию и разобрать результаты. [Собрать и установить плагин](plugins/README.md#build-and-install).

## Один продукт, два пакета

**Evolution Lab** (`evolution-lab`, в [`lab/`](lab/README.ru.md)) — рекомендуемый способ запускать Evolution. Lab превращает проект вашего агента в воспроизводимый эксперимент: фиксирует входные данные, запускает агента как локальный сервис, проверяет, что он говорит по протоколу, ограничивает расходы на LLM, выполняет оценку или кампанию и выдаёт отчёт, diff и экспорт. Всё доступно через команду `lab` и Python API; браузерная панель не обязательна.

**Core** (`evo-skills`, команды `evo` и `evo-target`) отвечает за саму кампанию: правила, измерения, журналы, гейты сравнения и продвижение версии. Lab запускает Core за вас. Используйте Core напрямую, когда сами пишете манифест и сервис агента, запускаете кампании из CI или встраиваете их в свой инструмент: начните со страницы [Core Evolution](docs/core.ru.md).

## Перед началом

- **Linux или macOS.** На Linux Lab отслеживает дочерние процессы через `/proc`. На macOS процесс, вышедший из группы и дерева между проверками и скрывший маркер окружения, может пережить остановку. Windows не поддерживается.
- **Python 3.12 или 3.11** (3.11.4 или новее). uv скачает интерпретатор, если его нет.
- **[uv](https://docs.astral.sh/uv/)**, **[just](https://just.systems/)** и **git**.
- Доступ на чтение к этому репозиторию. [Руководство по установке](docs/guide/ru/install.md) перечисляет все требования и описывает ручную установку.

## Первый запуск

Около пяти минут. После установки демо работает офлайн: без LLM, без сети и без API-ключей.

```sh
git clone https://github.com/sb-ai-lab/evolution.git
cd evolution/lab
just setup
just demo
```

`just setup` собирает wheel Core и Lab из этого checkout и ставит оба в `lab/.lab/venv`. `just demo` измеряет агента-заглушку полной фиксированной оценкой и печатает каждый вопрос с ответом агента и баллом. [Демо](docs/guide/ru/demo.md) объясняет, что вы видите и какие файлы открыть.

[Быстрый старт](QUICKSTART.ru.md) продолжает с вашим собственным агентом и первой кампанией.

## Улучшение инструкции начинается с конкретной ошибки.

Агент даёт общие советы по удержанию пользователей, не проверяя данные продукта. Исследование выявляет недостающий запрос. В предложенной версии навыка теперь сказано запросить данные и сравнить когорты по удержанию. Evolution проверяет кандидата; ваши проверки определяют, будет ли он выбран.

Вы предоставляете агента, редактируемые файлы, кейсы и оценщик. Evolution меняет файлы инструкций, не обучая веса модели. Обучающие данные направляют правки и выбор; отложенные кейсы отдельно измеряют зафиксированную выбранную версию. Ошибка инфраструктуры никогда не засчитывается как качество агента, а «улучшения нет» — допустимый ответ.
