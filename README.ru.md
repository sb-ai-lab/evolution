# Evolution Core

[English](README.md) · [Русский](README.ru.md)

Превращайте ошибки своего агента в предлагаемые изменения его навыков и промптов. Core проверяет каждое изменение на ваших кейсах, прежде чем выбрать версию.

Core — это пакет `evo-skills` с командами `evo` и `evo-target`. Ему принадлежат правила кампании, измерения, журналы, гейты сравнения и продвижение версии. Вы предоставляете агента за Target Service, редактируемые файлы, кейсы и оценщик. Core сохраняет выбранные файлы и историю запусков, а кампания может сохранить текущую версию.

Python 3.11.3+ · Бета `2.0.0b21` · [Apache 2.0](LICENSE)

## Когда использовать Core напрямую

Используйте Core напрямую, когда сами пишете манифест и Target Service, запускаете кампании из CI или другой программы или встраиваете оценку кампаниями в свой инструмент. Команды, манифест и файлы запуска, описанные на этих страницах, — полный интерфейс; больше ничего не нужно.

## Установка

```bash
git clone https://github.com/sb-ai-lab/evolution.git
cd evolution
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[tree]"
evo --version
```

Ожидаемый вывод — `evo 2.0.0b21`. Extra `tree` устанавливает команды кампаний и помощники для Target Service. Обычная установка из PyPI может установить другой выпуск. На странице [Ваша первая кампания](QUICKSTART.ru.md#1-установите-бета-версию) описана и установка из предоставленного wheel-файла.

## Первая кампания

[Ваша первая кампания Evolution](QUICKSTART.ru.md) проводит полный офлайн-пример без API-ключа: создать пример, запустить его Target Service, проверить подключение, выполнить кампанию и прочитать выбранные файлы.
